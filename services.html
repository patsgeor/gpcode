Υπηρεσίες

Υπηρεσίες ανάπτυξης λογισμικού

Επτά υπηρεσίες, από μια σελίδα παρουσίασης μέχρι τη διασύνδεση συστημάτων. Διαλέξτε από πού θέλετε να ξεκινήσουμε — ή περιγράψτε το πρόβλημα και θα σας πω εγώ πού ανήκει.

Κατασκευή ιστοσελίδων

Μια εταιρική ιστοσελίδα που φορτώνει γρήγορα, διαβάζεται σωστά σε κάθε οθόνη και βρίσκεται στη Google. Χωρίς πλατφόρμες που σας δεσμεύουν και χωρίς δεκάδες plugins που θα σπάσουν στην πρώτη ενημέρωση.

Κατασκευή Ιστοσελίδων

Ανάπτυξη web εφαρμογών

Όταν η δουλειά σας ζει σε δέκα αρχεία Excel και τρία email threads, δεν χρειάζεστε ιστοσελίδα — χρειάζεστε σύστημα. Χτίζω εφαρμογές που κωδικοποιούν τις δικές σας διαδικασίες, όχι τις διαδικασίες ενός έτοιμου πακέτου.

Web Εφαρμογές

Ανάπτυξη σε .NET

Το .NET είναι η βασική μου πλατφόρμα. Από ένα Web API που εξυπηρετεί μια εφαρμογή Angular, μέχρι τη σταδιακή μετάβαση μιας εφαρμογής Web Forms που δουλεύει από το 2012 και δεν επιτρέπεται να σταματήσει.

.NET Development

Ανάπτυξη σε Angular

Το Angular ταιριάζει εκεί που η εφαρμογή έχει πολλές οθόνες, πολλές φόρμες και δεδομένα που αλλάζουν συνέχεια. Δεν είναι όμως η απάντηση για κάθε έργο — και σας το λέω πριν το ξεκινήσουμε, όχι μετά.

Angular Development

Σχεδίαση βάσεων δεδομένων

Τα περισσότερα προβλήματα «η εφαρμογή είναι αργή» είναι στην πραγματικότητα προβλήματα βάσης. Ένα ερώτημα χωρίς index, ένα σχήμα που φτιάχτηκε βιαστικά, ένα N+1 που κανείς δεν πρόσεξε.

Βάσεις Δεδομένων

Ανάπτυξη API

Ένα API είναι ο τρόπος που δύο συστήματα συνεννοούνται χωρίς να μεσολαβεί άνθρωπος με ένα αρχείο Excel. Σχεδιάζω APIs που άλλοι developers μπορούν να χρησιμοποιήσουν χωρίς να σας τηλεφωνήσουν.

API Development

Τεχνική συμβουλευτική

Έχετε μια προσφορά στα χέρια σας και δεν ξέρετε αν είναι λογική. Ή μια εφαρμογή που «κάτι δεν πάει καλά» και κανείς δεν σας εξηγεί τι. Πληρώνετε για μια γραπτή, τεκμηριωμένη γνώμη — όχι για να σας πουλήσω το επόμενο έργο.

Τεχνική Συμβουλευτική
Δεν ξέρετε ποια υπηρεσία σας ταιριάζει;

Είναι το συνηθέστερο σημείο εκκίνησης. Περιγράψτε τι δεν λειτουργεί σήμερα και θα σας πω τι χρειάζεται — ακόμη κι αν η απάντηση είναι ότι δεν χρειάζεστε τίποτα από όσα κάνω. Δείτε επίσης τις συχνές ερωτήσεις.
