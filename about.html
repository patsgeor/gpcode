Ο developer πίσω από το gpcode

Το gpcode δεν είναι εταιρεία με τμήματα. Είναι ένας developer που αναλαμβάνει έργα από άκρη σε άκρη και βάζει το όνομά του πάνω τους.

Ποιος είμαι

Ονομάζομαι Γεώργιος Πατσιαλής και γράφω λογισμικό. Δημιουργός του GPcode.

Δουλεύω κυρίως στο οικοσύστημα .NET: backend σε ASP.NET Core και C#, frontend σε Angular όταν το έργο το χρειάζεται, και βάσεις δεδομένων σε SQL Server, PostgreSQL ή Oracle. Αυτό σημαίνει ότι σε ένα τυπικό έργο δεν χρειάζεται να συντονιστούν τρεις άνθρωποι για να αλλάξει ένα πεδίο σε μια φόρμα.

Αναλαμβάνω και μικρά έργα — μια landing page, ένα script που διορθώνει δεδομένα, έναν τεχνικό έλεγχο σε προσφορά που έχετε ήδη στα χέρια σας. Δεν υπάρχει ελάχιστο μέγεθος έργου, υπάρχει μόνο ελάχιστη σαφήνεια για το τι θέλουμε να πετύχουμε.

Γεώργιος Πατσιαλής — Καισαριανή, Αθήνα.

Αρχές

Πώς δουλεύω

Πέντε πράγματα που ισχύουν σε κάθε έργο, ανεξάρτητα από μέγεθος και προϋπολογισμό.

Γραπτά, πριν ξεκινήσουμε

Αντικείμενο, τιμή, χρονοδιάγραμμα και ρητά όσα ΔΕΝ περιλαμβάνονται. Οι παρεξηγήσεις κοστίζουν πάντα περισσότερο από τον χρόνο που θέλει η καταγραφή.

Χωρίς ορολογία που δεν χρειάζεται

Θα σας εξηγήσω τι σημαίνει η κάθε τεχνική απόφαση για το κόστος και τον χρόνο σας. Αν κάτι δεν έγινε κατανοητό, το λάθος είναι δικό μου.

Το απλούστερο που λύνει το πρόβλημα

Δεν προτείνω αρχιτεκτονική για κλίμακα που δεν έχετε. Η υπερμηχανική είναι το ίδιο ακριβή με την προχειρότητα, απλώς φαίνεται αργότερα.

Θα ακούσετε και «όχι»

Αν το WordPress σας κάνει, θα σας το πω. Αν ένα έργο είναι εκτός των δυνατοτήτων μου ή του χρόνου μου, θα σας το πω πριν το αναλάβω και όχι στη μέση.

Χωρίς κλείδωμα σε πλατφόρμα

Το domain, το hosting και τα credentials πρόσβασης είναι πάντα στα δικά σας στοιχεία. Ο πηγαίος κώδικας παραμένει δικός μου, με σαφή άδεια χρήσης για εσάς.

Τεχνολογίες

Το τεχνολογικό μου στοίβαγμα

Δείτε αναλυτικά τι χρησιμοποιώ και γιατί στις σελίδες .NET, Angular και βάσεων δεδομένων.

Backend

ASP.NET Core

Ώριμο, γρήγορο και cross-platform — τρέχει το ίδιο σε Windows και Linux.

C#

Στατικοί τύποι που πιάνουν λάθη στο compile, όχι στην παραγωγή.

Entity Framework Core

Για CRUD και μοντέλα που αλλάζουν συχνά, με migrations υπό έλεγχο.

Dapper

Εκεί που το ερώτημα πρέπει να είναι ακριβώς αυτό που έγραψα.

REST & OpenAPI

Τεκμηριωμένα endpoints που τα καταναλώνει οποιαδήποτε ομάδα.

Frontend

Angular

Δομημένο framework για εφαρμογές με πολλές οθόνες και φόρμες.

TypeScript

Το ίδιο επιχείρημα με τη C#, μεταφερμένο στον browser.

HTML5 & CSS3

Semantic markup και σύγχρονο CSS αντί για στρώματα abstraction.

Bootstrap 5

Σταθερό grid και components, με purge ώστε να μείνει μόνο ό,τι χρησιμοποιείται.

Vanilla JavaScript

Για στατικά sites, όπου ένα framework θα ήταν καθαρό βάρος.

Δεδομένα

SQL Server

Το προεπιλεγμένο ταίρι του .NET, με εξαιρετικά εργαλεία διάγνωσης.

PostgreSQL

Όταν το κόστος αδειών μετράει ή χρειάζεται JSONB και extensions.

Oracle PL/SQL

Για περιβάλλοντα που ήδη τρέχουν σε Oracle και δεν αλλάζουν.

Database design

Σωστή κανονικοποίηση, constraints και indexes πριν γραφτεί κώδικας.

Query optimisation

Execution plans αντί για εικασίες όταν κάτι αργεί.

Εργαλεία & υποδομή

Git

Ιστορικό αλλαγών που παραδίδεται μαζί με τον κώδικα.

Docker

Ίδιο περιβάλλον σε development και production.

CI/CD pipelines

Αυτόματο build και deploy, ώστε η παράδοση να μην εξαρτάται από άνθρωπο.

IIS & Linux hosting

Deployment εκεί που ήδη βρίσκεστε, χωρίς μετακόμιση.

Lighthouse & DevTools

Μετρήσεις απόδοσης αντί για υποκειμενικό «φαίνεται γρήγορο».

Ένας developer αντί για agency

Αυτή η επιλογή έχει και τις δύο όψεις. Παρακάτω είναι και οι δύο, χωρίς ωραιοποίηση — γιατί αν τη μάθετε στη μέση του έργου, θα είναι ήδη αργά.

Τι κερδίζετε

  • Μιλάτε απευθείας με αυτόν που γράφει τον κώδικα
  • Καμία απώλεια πληροφορίας μεταξύ ομάδων
  • Χαμηλότερο κόστος χωρίς overhead δομής
  • Γρήγορες αποφάσεις σε αλλαγές

Τι δεν κερδίζετε

  • Υποστήριξη 24/7 ή βάρδιες
  • Παράλληλες ομάδες σε πολλά μέτωπα
  • Κάλυψη σε άδεια ή ασθένεια
  • Ξεχωριστό γραφικό σχεδιαστή στο ίδιο πακέτο
Πώς αντισταθμίζεται το ρίσκο

Το domain και το hosting είναι πάντα στα δικά σας στοιχεία, οπότε το site ή η εφαρμογή δεν εξαρτώνται από τη δική μου συνέχεια για να παραμείνουν online. Ο πηγαίος κώδικας παραμένει δικός μου, με σαφή άδεια χρήσης για εσάς· αν θέλετε εκ των προτέρων όρο πρόσβασης σε αυτόν για συγκεκριμένη περίπτωση, το συζητάμε και μπαίνει γραπτώς στη σύμβαση.

Νομικά και τιμολόγηση

Τα πλήρη στοιχεία είναι δημόσια και επαληθεύσιμα. Στην Ελλάδα οι επιχειρήσεις ελέγχουν συχνά τον ΑΦΜ ενός συνεργάτη πριν την πρώτη ανάθεση — και σωστά κάνουν.

  • Εκδίδεται τιμολόγιο παροχής υπηρεσιών για κάθε συνεργασία
  • Πληρωμή με τραπεζική κατάθεση ή έμβασμα
  • Υπογραφή NDA όπου απαιτείται, πριν σταλεί οτιδήποτε

Πώς μπορείτε να επαληθεύσετε τη δουλειά μου

Το gpcode είναι νέο ως μάρκα και δεν έχει ακόμη δημοσιευμένο πελατολόγιο. Αντί να σας ζητήσω να με εμπιστευτείτε στα λόγια, ορίστε τέσσερις τρόποι να ελέγξετε μόνοι σας.

Αυτό το site είναι το δείγμα

Δεξί κλικ, «Προβολή πηγαίου κώδικα». Θα δείτε semantic HTML, structured data και μηδέν κλήσεις σε τρίτους πριν δώσετε συγκατάθεση. Τρέξτε του PageSpeed Insights και συγκρίνετε το με σελίδες ανταγωνιστών.

Τεχνική κλήση 30 λεπτών

Χωρίς χρέωση και χωρίς δέσμευση. Ρωτήστε ό,τι θέλετε για την προσέγγιση, την αρχιτεκτονική ή το κόστος. Αν έχετε δικό σας τεχνικό, καλέστε τον μαζί.

Δείγμα κώδικα κατόπιν αιτήματος

Μπορώ να μοιραστώ κώδικα από έργο που δεν καλύπτεται από NDA, ή να κάνω screen share σε πραγματικό repository ώστε να δείτε πώς γράφω και πώς τεκμηριώνω.

Ξεκινήστε με έναν τεχνικό έλεγχο

Ένα audit σταθερής τιμής είναι ο χαμηλού ρίσκου τρόπος να δουλέψουμε πρώτη φορά μαζί. Παίρνετε γραπτή αναφορά που μπορεί να χρησιμοποιήσει και άλλος developer, χωρίς καμία δέσμευση για συνέχεια.
